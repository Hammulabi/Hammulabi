## Développeur FullStack & Créateur de Produits
Développeur passionné par la création de solutions numériques utiles, je cherche à
transformer des idées en applications concrètes avec une attention particulière portée à la
qualité du code, à l’architecture et à l’expérience utilisateur. Je travaille principalement sur
des projets web, outils métiers, et interfaces 3D.

# Stack & Compétences:
Langages :
- TypeScript,
- Python,
- Java
Frontend :
- React,
- Next.js,
- TailwindCSS 
Backend:
- Node.js,
- Express,
Base de données:
MySQL, MongoDB, SQLite

# Projets et réalisations
- SceneLab3D
Outil web permettant de créer et manipuler des scènes 3D.
Stack : TypeScript, React, Three.js
Objectif : Rendre la création 3D accessible via une interface intuitive. →

- Mini Gestion Commerciale
Application Java de gestion commerciale (produits, clients, commandes). Tech :
Java, Swing Objectif : Projet pédagogique pour comprendre la structure d’une
application métier.

- LedgerOne Proof of Concept (POC)
«Application Web de gestion de dépenses (API FastAPI + Frontend HTML/JS) »
LedgerOne, une entreprise fictive spécialisée dans les outils de gestion financière
personnelle, souhaite développer un Proof of Concept pour une application web permettant
de suivre et analyser des dépenses. Ce projet académique a été réalisé dans le cadre d’un
test technique qui vise à reproduire une mission réelle qui pourrait être mené un intervenant
JEECE.
